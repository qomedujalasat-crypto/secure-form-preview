# پیش‌نمایش سامانه ثبت درخواست

این مخزن فقط شامل پیش‌نمایش عمومی رابط کاربری فارسی و راست‌چین فرم ثبت درخواست است.

- هیچ اطلاعاتی به سرور ارسال یا در جایی ذخیره نمی‌شود.
- کد ملی و شماره موبایل واقعی وارد نکنید.
- پایگاه داده، احراز هویت پیامکی و منطق ثبت درخواست به این صفحه متصل نیست.
- سامانه اصلی در مخزن خصوصی جداگانه نگهداری می‌شود.

## انتشار با GitHub Pages

در تنظیمات مخزن، از بخش **Settings → Pages**، گزینه **Deploy from a branch** را انتخاب کنید، شاخه `main` و پوشه `/(root)` را ثبت کنید. پس از انتشار، آدرس صفحه معمولاً `https://qomedujalasat-crypto.github.io/secure-form-preview/` خواهد بود.
